# 🩺 Landing Page Doctor

An immersive and premium landing page for Dr. Carlos Mendes, orthopedist and traumatologist, built with modern web technologies focused on fluid interactions, cinematic animations, and high-end UI/UX.

## 🖼 Features

- ⚡ Scroll storytelling with GSAP ScrollTrigger
- 🎨 Premium dark UI with blue accent and glow effects
- 🩺 Hero section with animated character reveal
- 📊 Animated stats counters with scroll trigger
- 🏥 Specialties, Services, and Testimonials sections
- 💬 Contact section with React Hook Form + Zod validation
- ✨ Floating particles canvas background (global)
- 🔵 Parallax orbs with GSAP scrub
- 🎬 Framer Motion entrance and stagger animations
- 📱 Fully responsive — mobile-first layout
- 🔍 Full SEO setup with Open Graph and Twitter Cards
- 🚀 Built with Next.js App Router

---

## 🛠 Technologies

- Next.js 16 (App Router)
- React 19
- TypeScript
- TailwindCSS v4
- GSAP + ScrollTrigger
- Framer Motion
- React Hook Form + Zod
- Lucide React
